Spotify Music Data Analysis (EDA Project)

Objective:
A data analysis project completed during my First Year B.Sc. Data Science program, 
exploring Spotify music data to uncover insights into song popularity and audio features.

Tools & Libraries Used:
Python
Pandas
NumPy
Matplotlib
Seaborn

Steps Performed:
(1) Data Cleaning-
Removed duplicates and missing values.
Checked data types and converted where needed.
(2) Exploratory Data Analysis (EDA)-
Distribution of song popularity.
Correlation analysis between numeric features.
Visualization of top artists based on popularity
Relationship between energy, danceability, and loudness
(3)Visualization-
Used bar charts, heatmaps, histograms, and scatter plots.

>Dataset:
Source- [Spotify Tracks Dataset by Maharshi Pandya] (https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset)
Platform - Kaggle
Description - This is a dataset of Spotify tracks over a range of 125 different genres. Each track has some audio features associated with it.
